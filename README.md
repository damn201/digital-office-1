# Hermes Pages Sites

Halaman status statis untuk Cloudflare Pages (satu repo, dua proyek):

- `hermes-office/` -> proyek Pages `hermes-office` (hermes-office.pages.dev)
- `router-9/` -> proyek Pages `router-9` (router-9.pages.dev)

Pengaturan Pages untuk masing-masing proyek:

- Production branch: `main`
- Build command: (kosong — tidak ada build)
- Build output directory: `.` (root dari folder proyek)
- Root directory: `hermes-office` atau `router-9`

Catatan: ini hanya halaman status statis. Aplikasi Hermes Office dan
9Router yang sebenarnya adalah aplikasi server dan tetap berjalan di
komputer lokal, dibuka lewat Cloudflare Tunnel.
